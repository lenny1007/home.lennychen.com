## 表格上下方原文
- ASG／ASW13T：「● 顯示運轉的燈號會急速閃爍，並以代碼顯示通知發生的錯誤。」表頭：錯誤顯示・內容／確認事項／重新開始。ASW13T 通知表上方：「● 如有以下狀況，非異常故障。」
- ASF：「● 讓正在亮燈、閃爍的行進顯示（「洗衣」「洗清」等指示燈）快速閃爍，並以下列顯示進行通知。」
- FKA105WDT 表下：「如果嘗試解決方法後仍無法排除問題，請與台灣夏普客戶服務中心聯繫。」

## 不明確的地方

- `E19` 那格沒有自己的中文標題，排在「無法脫水」大格裡（與 E4 共用）；我在 TSV 標「（列在「無法脫水」欄下）」。
