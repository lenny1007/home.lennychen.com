## TSV 欄位（`sharp-aircon-codes.tsv`）
`code<TAB>models<TAB>meaning<TAB>action<TAB>source`——比交辦多一欄 `source`（圖檔名），方便回查原圖。
- code：圖上代碼；ZAMH／VAMH 的「主要-次要」連字號是轉錄時加的（表格原本分兩欄印數字，格式依原稿示例「錯誤 23-4」）。後面用「｜」附燈號／室外機 LED／問題症狀原文。
- meaning：故障內容原文；ZAMH／VAMH 用「主要的：…｜次要的：…」標籤。
- action：**全部是給維修人員的「檢查點／對策」或「可能故障原因/零件」，不是給一般使用者的處理步驟**。原圖沒有面向使用者的處理欄。
- 儲存格內換行改「／」；合併儲存格每列重複填入。
- ZAMH 一列＝一個代碼（同代碼的多個檢查點用「／」串接）。ZAMH 圖 12 的「單元間接線錯誤模式 1–5」也收成 5 列（code 欄寫明「單元間接線錯誤模式」），不是另外的故障碼。
- 注意：附錄裡 ZAMH-b（圖 08–12）筆記的列數是「每個檢查點一列」（49 列）；合併進 TSV 時我把同一代碼的列併成一列（31 列，檢查點／對策依序用「／」串接），與 ZAMH-a 一致。

## 有疑問／要注意的地方（寫文章前請再看原圖）
1. **「末」與「未」**：原稿多處印的字形是「末」（例「室內機末運行時」「均末發現異常」）。說明文字（notes）照抄成「末」，但 TSV 裡有些「均未發現異常」「跳線帽未安裝」「IPM模塊未鎖緊」轉錄成「未」（驗收抽到 6 列：TSV 第 16、17、19、20、24、40 行）。意思相同，逐字引用時請以「未」為準並視為原稿誤植。
2. TSV 中標「[?]」的 3 處：ZAMH 9-4「換器散[?]熱敏電阻」（字被壓縮重疊）；BESH「PCOF[?]」（第三字元看起來是字母 O，原意可能是 PC0F）；VAMH 14-2 計時器燈只在第 5 格印 o（其他代碼都是 5 格全 o，疑似原稿漏印）。
3. 原稿明顯錯字照抄：「冷冷媒」「熱敏電組」「熱交換氣」「使否」「安裝安裝」「之間的的」「室外/室外機主控板」等；ZAMH 12-0、11-5、19-0 與 VAMH 19-0 的項目編號原稿就對不上。
4. ZAMH 6-3 對策寫「見流程圖。」，但頁面上沒有流程圖。
5. AESH 的 F0（數字零）與 Fo（小寫 o）是兩個代碼、名稱都是「冷媒防漏保護」；cF 代碼格有紅框，原因未說明；oE 無原因欄。
6. 代碼頁沒有連到說明書。另查「說明書下載」冷氣空調系列（category=230、使用者手冊）只有 4 份（2026-11-19，全標「現行產品」）：
   - AE-71WESH、AE-50WESH、AE-40WESH、AE-36WESH、AE-28WESH、AE-22WESH使用說明書（41.62 MB）
   - AE-22YTSH-Z、AE-28YTSH-Z、AE-40YTSH-Z、AE-50YTSH-Z、AU-22YTSH-Z、AU-28YTSH-Z、AU-40YTSH-Z、AU-50YTSH-Z使用說明書（45.24 MB）
   - AY-28ZAMH-W、AY-36ZAMH-W、AY-40ZAMH-W、AY-50ZAMH-W、AY-63ZAMH-W_AIoT使用說明書（2.9 MB）
   - AY-28ZAMH-W、AY-36ZAMH-W、AY-40ZAMH-W、AY-50ZAMH-W、AY-63ZAMH-W使用說明書（5.72 MB）
   這幾份手冊沒有下載、沒有比對；若文章要寫「適用型號」，可從這裡推 WESH 與 ZAMH 的具體型號（BESH、AESH、VAMH 在下載頁沒有對應手冊）。

### TSV 的編排約定（不是圖上的字，是轉錄格式）
- 表格只有一張（跨 03–06 頁連續），欄位原文：「問題症狀｜室外機指示(LED1)｜室內機故障代碼（主要的／次要的）｜診斷內容（主要的／次要的）｜檢查點｜對策」。
- TSV 一列 = 表上一個「主要的＋次要的」代碼組合。圖上同一代碼的檢查點／對策被橫線再細分成多格（例：2-0 有 5 格、9-0 有 4 格、7-3 有 3 格），這些細格依序用「／」串在同一列，沒有拆成多列。
- code 欄寫成「主要的-次要的」（例 1-0），此寫法依圖 1-ZAMH-03 的「示例：錯誤 23-4」與遙控器顯示「-4」的格式；圖上表格本身是分兩欄印「1」「0」，沒有印連字號。其後以「｜」附「室外機指示(LED1) N次」與「問題症狀 …」原文。
- meaning 欄 =「主要的：<診斷內容 主要的>｜次要的：<診斷內容 次要的>」；0-0 列的診斷內容是跨兩欄的「正常狀態」。
- action 欄 =「檢查點：…｜對策：…」，兩欄都是給維修人員的內容，照抄未改寫。編號項目 (1)(2)… 另起一行者以「／」分隔；同一項自動折行者直接接續。
- 合併儲存格（問題症狀、LED、主要代碼、主要診斷、共用的檢查點／對策）每列重複填入。共用情形：1-0～1-3 共用一組檢查點／對策；2-1～2-4 共用檢查點「(1)暫停循環保護。」；5-0～5-5 共用；6-0、6-1 共用對策「更換室外機IPM電路板組件。」；10-0～10-3 共用檢查點「-」與對策。
- 2-0 在頁 03（問題症狀「室內機和室外機不運轉」），2-1～2-5 在頁 04；2-1～2-4 的問題症狀是「室內機運轉。室外機不運轉」，2-5 是「室內機和室外機不運轉」。

## (c) 代碼呈現方式（依圖原文）
- 室內機：「運行指示燈 (綠色)、定時指示燈 (橙色) 和 WLAN 指示燈 (綠色) 會閃爍以顯示故障信息」——指示燈閃爍組合；運行燈與定時燈閃爍次數組成主要代碼（範例 23 = 運行燈 2 次、定時燈 3 次），WLAN 燈閃爍次數為次要代碼（範例 -4）。進入方式：室內機未運行時長按 ON/OFF 按鈕超過 5 秒。
- 遙控器：長按溫度「﹀」超過 5 秒顯示 "00"，逐步按到主要代碼時蜂鳴器長音，再按風量鍵切到 "-0" 逐步按到次要代碼時長音——數字顯示在遙控器螢幕上（不是室內機面板）。
- 室外機：「通過 LED1 閃爍顯示錯誤信息」，顯示約 3-10 分鐘；表格欄「室外機指示(LED1)」為「正常閃爍」或「N次」（1～10次），且 N 次與主要代碼 N 一致。

## (c) 代碼的呈現方式（依圖原文）

- 依頁首說明，要在室內機長按「AUX」按鈕超過5秒，才會顯示自我診斷信息。
- 室內機用三顆燈號表示：「計時器(橙色)」「操作(綠色)」「(藍色)」，每顆燈對應一列 5 格，格內印「o」。圖上沒有寫「o」代表亮燈還是閃爍。
- 同一列另有「室外機指示(LED1)」欄，寫的是次數（例如「1次」「13次」）或狀態（「正常閃爍」「照明或離開」「正常閃爍或離開」「正常閃爍或關閉」）。
- 故障編號分成「主要」「次要」兩欄數字。圖上表格裡沒有連字號，但 4-VAMH-24.jpg 的 6-0 檢查點自己寫成「(6-0錯誤)」，所以 TSV 的 code 欄用「主要-次要」格式（例如 1-0）。
- 結論：這個系列的代碼不在面板上直接顯示文字代碼，而是用室內機三顆指示燈的「o」組合，加上室外機 LED1 的閃爍次數或狀態來表示。
- 轉錄者觀察（不是圖上文字）：除了計時器列全 5 格都有 o，操作(綠色)列的 5 格剛好是主要編號的二進位（16/8/4/2/1），(藍色)列是次要編號的二進位。每一列都對得上，可以用來核對；唯一例外是 14-2 的計時器列（見 (d)）。

### TSV 欄位編碼說明

- code：`主要-次要｜室外機指示(LED1) <原文>｜計時器(橙色)xxxxx 操作(綠色)xxxxx (藍色)xxxxx`。5 個字元由左到右對應 5 個格子：「o」表示圖上該格印了 o，「-」表示該格空白。「-」是轉錄用的符號，圖上沒有。
- meaning：`問題症狀：…；主要的：…；次要的：…`，標籤取自表頭。0-0 的「正常狀態」橫跨主要的、次要的兩欄，所以寫成「診斷內容：正常狀態」。
- action：`檢查點：…；對策：…`。檢查點或對策分成不同儲存格時，用「／」分隔；同一個儲存格內的 (1)(2)… 直接接續，因為原文只是自動換行。圖上印的「–」短橫照抄為「-」。
- 合併儲存格（跨多個代碼的 問題症狀、LED1、主要的、檢查點、對策）都重複填到每一列。
- 4-VAMH-24.jpg 的 6-0：「(1)轉到「直流過流錯誤」(6-0錯誤)」一格橫跨檢查點、對策兩欄，所以 TSV 兩欄都填這句。

## (c) 代碼呈現方式（依圖原文）
圖上同一列同時印有「燈號閃爍(次數)」與「故障代碼」兩欄，例如 E0 對應「1次」。圖上沒有說明是哪一個燈閃、也沒有說明故障代碼顯示在哪裡（面板或其他），也未區分室內機／室外機表——只有這一張表（跨兩頁）。故只能依原文表述為：「燈號閃爍(次數)」＋「故障代碼」，不得推論為面板顯示或室外機 LED。

注意：閃爍次數與代碼並非一對一，同一次數重複出現（如 E0 與 F0 都是 1次、E1/F1/P1 都是 2次），且 E7 為「9次」、EC 為「7次」（照圖原樣，未調整順序）。

## 轉錄處理說明
- code 欄格式：「故障代碼｜燈號閃爍N次」，其中「燈號閃爍」取自表頭字樣，「N次」為儲存格原文。
- models 欄：取頁首「適用機型：經典系列(WESH)」的「經典系列(WESH)」；表格內無機型欄。
- meaning 欄＝「故障名稱」欄。此欄多處因欄寬自動折行（如「室外機主控晶片與驅動晶片／通信故障」），屬版面折行而非語意換行，轉錄時直接接續不加「／」，以免把一個詞切開。字串內「/」（如「護/341MCE故障」「模組保護/硬」）是圖上原有的半形斜線，照抄。
- action 欄＝「可能故障原因/零件」欄（給維修人員的零件檢查清單，非使用者處理方式），每項前方圓點「·」省略，各項以「／」分隔。
- 序號 11：序號儲存格與「可能故障原因/零件」儲存格跨 F2、F3 兩列合併，兩列皆重複填入相同原因。
- 序號欄未放入 TSV（題目未要求），對應見上方列數。
