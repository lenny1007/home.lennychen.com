# 聲寶（SAMPO）故障碼：官方「聲寶技術資訊站」

- 網站：https://sampo-errorcode.com.tw/ （頁首標「聲寶技術資訊站」；頁尾「聯絡窗口： 聲寶客服中心」、電話 0800-00-5438、連回 https://www.sampo.com.tw/ 、「Copyright © 2022 SAMPO. All Rights Reserved.」）
- 頁首警語原文：「非修理技術人員請勿自行拆解及修理，維修請洽聲寶服務中心。」
- 2026-11-19 以 App 內建瀏覽器操作取得（網站擋 curl：直接抓會回 302；我沒有繞過，全部在瀏覽器裡用網站自己的查詢頁讀，請求間隔 120–250 ms）。
- 查詢方式：選「產品類別」（空調／洗衣機／冰箱）→「查詢項目＝故障代碼」→ 系列 → 機型 → 全部代碼，結果頁網址格式：
  `https://sampo-errorcode.com.tw/error-code?class=<1空調|2洗衣機|3冰箱>&type=3&series=<id>&model=<id>&error_code=all`
  每個代碼再點「查看說明」到 `https://sampo-errorcode.com.tw/error-code/<detail_id>?class=…`，頁面欄位是「故障內容」與「故障說明」。
- 文件編號／版本：網站沒有印。說明圖檔路徑上的日期是 2022-06 到 2022-07。

## 檔案
- `sampo-error-codes.tsv`：欄位 product／code／models（「系列｜機型」，多個用「；」隔開）／meaning（網站「故障內容」原文）／action／detail（網站「故障說明」原文）／detail_ids（`/error-code/<id>` 的 id，可用來回查）。
  - 原始抓取 713 列（69 個「系列＋機型」組合），內容完全相同的列已合併（同一代碼、同一故障內容、同一故障說明，只是機型不同）→ 258 列。
  - 網站沒有獨立的「使用者處理方式」欄。冷氣的處理方式寫在「故障說明」裡（而且多半是技師用語：換機板、塗散熱膏、量通訊電壓），所以放在 detail 欄，action 欄留空。
  - 洗衣機的「故障說明」文字全部是「無」，真正的檢查方法／再啟動方法放在一張說明圖裡。我只把 **PICO PURE／ES-N17DV／超震波（共 10 型）那張圖** 轉錄到 action 欄（標「轉錄自說明圖」），其他系列的圖沒轉錄，圖片網址前綴是 `https://sampo-errorcode.com.tw/storage/upload/admin.html-editor/image/`，後面接 TSV 裡寫的日期/檔名。
  - 冷氣有 229 個代碼頁附示意圖，沒抓圖。

## 不明確／要注意
- 同一系列的代碼意思不一定一樣：壁掛PF/NF「1」＝室外銅管溫度感測器故障，壁掛SF「1」＝室外盤管溫度感測器故障；吊隱NF/SF 的「1」＝室外熱交溫度感測器故障。一定要按系列分開寫。
- 壁掛QC 有兩套：QC22-80D/DC（E0–P6，帶文字說明）與 QC93-110D／吊隱 QC93-140D（同一個 E1 對應 4 種情況，用室外機 LED 閃法區分）。
- 一對多QC 網站列了兩份一模一樣的代碼清單（detail id 226–245 與 303–322），我合併了。
- 一對多PF AU-PF140DC4 的 07 網站寫「是內外機通訊異常」（應是錯字），照抄。
- 窗型PF AW-PF28D 的 EC51、EC52 詳細頁空白；AW-PF65D 的 E0、F4 詳細頁只有圖。
- 吊隱SF「說明」頁的文字以「無」開頭再接說明，照抄。
- 網站網域是 sampo-errorcode.com.tw（不是 sampo.com.tw），但頁面標明聲寶客服中心為聯絡窗口、版權屬 SAMPO；我沒有在 sampo.com.tw 上找到連過來的入口來雙重確認，寫文章前可以再確認一次。
- 冷氣「故障說明」大多是技師層級（換機板、量電壓、塗散熱膏、冷媒），依站規只能寫「代碼意思」＋使用者層級（斷電重開、清濾網、報修），其餘用 `<SafetyNote />`。
