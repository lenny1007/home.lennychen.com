## 3. ES-P13DV／ES-P15DV：引言及 CodeTable 各列

以下均出自 A，第 28 頁「異常狀況時處理方法」，代碼以圖面逐列核對。

- 引言：「當洗衣機有異常發生時」「控制面板的"時間顯示"會做下列之顯示」。
- E1：「洗衣或洗清行程」「按「啟動/暫停」鍵後」「不能注水或注水超時」「是否打開了水龍頭？」「是否停水？」「給水管連接口的濾網是否堵塞？」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」
- E2：「上蓋開啟　不能洗衣」「不能脫水　不能注水」「不能排水」「蓋好上蓋後，自動啟動。」
- E3：「洗衣、洗清後不能排水」「排水管是否沒放下？」「排水位置是否太高或排水管被壓扁？」「延長水管是否太長？」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」
- E4：「不能脫水」「衣物在槽內是否偏於一側？」「洗衣機是否傾斜？」；圖說：「待旋轉完全停止後，將衣物均勻放平。」；再啟動：「處理完畢後，蓋好上蓋。」
- E5：「止水不良」「請拔下電源插頭，通知服務中心前來修理。」因此標示 `pro: true`。
- Ed：圖面字型為七段顯示 E 與小寫 d。「不能洗衣」「衣物是否過量？」「將衣物減量。」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」
- E9：圖面第二字為 9。「不能洗衣」「不能脫水」「排水管是否翹曲、不平順？」「桶內是否殘留水排不出去？」「是否連續過負荷洗衣？」；再啟動：「將排水管平放，約等15分鐘後。再按「啟動 / 暫停」鍵。」
- 本表為節錄；未列出圖面「其他異常」格的各個七段顯示代碼，也未替它們推論零件故障原因。

## 4. E4 的編號步驟

- A，第 28 頁，E4 圖說：「待旋轉完全停止後，將衣物均勻放平。」拆為步驟 1、2，保留先停轉的條件。
- A，第 28 頁，E4 再啟動欄：「處理完畢後，蓋好上蓋。」支援步驟 3。
- A，第 2 頁另提醒：「脫水槽未完全停止前，手絕勿觸摸。」

## 6. 滾筒 ES-PD13DH：CodeTable 與 SafetyNote

以下代碼及對應欄位均出自 C，第 38 頁，已逐列核對圖面，E10 最後一字是數字 0。

- E10：「不能注水」「是否打開了水龍頭？」「是否停水？」「給水管連接口的濾網是否堵塞？」「排水管高度是否低於60cm？」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」文章保留高度檢查原問句，未改成管路安裝指示。
- E21：「不能排水」「排水泵是否有小衣物進入？」「排水位置是否太高或排水管被壓扁？」「延長水管是否太長？」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」排水泵項目另置 SafetyNote，不提供內部拆修步驟。
- E30：「門鎖異常」「檢查洗衣機門是否關好？」「檢查洗衣機門是否有壓到衣物？」；再啟動：「處理完畢後，按下「啟動 / 暫停」鍵。」
- E3A、E37、E38 在同一格，對應「烘乾異常」；E12 對應「水位過高」。共用處理欄：「按「啟動 / 暫停」鍵，若無法消除異常」「請拔下電源插頭，通知服務中心前來修理。」標示 `pro: true`，文字保留「若無法消除」條件。
- C，第 2 頁：「不可改裝，非專業維修人員禁止分解及修理洗衣機。」支援 SafetyNote 的維修界線；不把排水泵檢查轉寫成自行拆卸步驟。

## 7. 不動作、按鍵沒反應

- A，第 27 頁；B，第 28 頁；C，第 37 頁，「不動作時」三份同列：「停電時，重新操作開關。」「插頭有沒插好？」「保險絲，斷電器斷了沒？」
- C，第 29 頁：「面板顯示CL表示設定童鎖成功。」
- C，第 29 頁：「設定「童鎖」功能後，按任何鍵」「除了電源 開 / 關鍵外」「都不能對洗衣機進行操作」。括號中的電源例外保留在文章。
- C，第 29 頁，取消設定：「同時按“烘乾選擇”及」「“加強洗淨”鍵4秒鐘完成設定」。文章只整理解除方式，未添加長按其他按鍵或重插電等方法。

## 8. 什麼情況要找原廠／服務站

- A，第 28 頁；B，第 29 頁；C，第 38 頁，共同註記：「依上述所示處理，異常狀況仍不消失時」「或有「嗶、嗶……」聲時」「請拔下電源插頭，通知服務中心前來修理。」文章保留「或」條件。
- 同上三頁，警告框：「請立即打電話到本公司客戶服務中心」「有漏電情形時。」「有漏水情形時。」「電源若需更換時。」
- A、B、C 均為第 2 頁，緊急處理：「發生異常時（有燒焦味等）」「請立即停止運轉，並拔掉電源插頭。」「請速與聲寶服務中心或就近經銷商洽詢。」
- A，第 28 頁；B，第 29 頁：「剎車機構故障時」「打開上蓋後，脫水槽應迅速停止迴轉」「否則即為剎車機構故障。」同頁要求立即聯絡服務中心；文章限定兩份直立式說明書。
