## 4. Tefal／綠生活陶瓷不沾鍋

### 第 1 段：預熱、用油與鍋鏟

- R，〈掌握使用秘訣〉：「中火預先熱鍋」。
- R，同節：「運用佳溫紅心科技掌握下鍋時機」。
- R，同節：「鍋中溫度達180°C，紅心圖案會感測變色。」
- R，同節：「加入少許食用油」。
- R，同節：「中火烹飪」。
- R，同節：「使用木鏟、耐熱膠鏟」。

180°C 僅寫成紅心變色與下鍋時機，沒有寫成耐熱或烤箱上限。

### 清洗步驟 1–4

- R，〈掌握使用秘訣／避免熱衝擊〉：「先讓鍋子冷卻再清洗」。
- R，〈掌握使用秘訣／使用軟性海綿手洗〉：「若食材燒焦，可將鍋子浸泡於含有中性清潔劑的溫水中。」
- R，同節標題：「使用軟性海綿手洗」。
- R，同節：「清洗後，再使用柔軟的布巾擦乾。」
