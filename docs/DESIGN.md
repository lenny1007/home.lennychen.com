# 設計方向

家的平面圖就是地圖。首頁一張平面圖，房間對應分類：客廳臥室＝冷氣、陽台＝洗衣機、儲藏室＝除濕機、廚房＝電鍋氣炸鍋與鍋具。

## Token（`src/styles/global.css`）
| token | 淺色 | 用途 |
|---|---|---|
| `--paper` | #F6F1E7 | 暖白紙底，像說明書紙張 |
| `--ink` | #2A2420 | 深咖啡字色 |
| `--tile` | #C2603A | 磁磚紅：重點、連結底線、平面圖選中房間 |
| `--sage` | #7C9A7E | 鼠尾草綠：次要標籤 |
| `--floor` | #EDE4D3 | 平面圖地板、表頭底色 |
| `--warn` | #B23A2B | 安全提醒、要叫原廠的錯誤碼 |

字體：標題 Noto Serif TC 700（明體，像說明書標題），內文系統黑體。

## 與其他站的區隔
badminton-tw：深綠＋羽球黃、Noto Sans／Space Grotesk。pickleball-tw：球場藍＋黃綠、Huninn 圓體、大圓角。本站：暖紙＋磁磚紅、明體標題、小圓角（6px）。

## 原則
- 大膽只用在平面圖一處，其他區塊用排版和留白。
- 錯誤碼一律用 `<CodeTable />`，要叫原廠的列標紅。
- 安全相關一律用 `<SafetyNote />`。
- 圖片分三種用途（2026-11-16 站主同意）：
  - **步驟／位置**：自己畫 SVG（`<Figure>`＋`src/components/figures/*.astro`），只畫說明書寫到的內容，不畫特定型號外觀，顏色只用 token；跟文字一樣要經獨立查證。目標每篇 1–2 張。
  - **實際操作**：嵌入品牌官方 YouTube 影片（`<VideoEmbed>`，點了才載入、從指定秒數播）。只用官方頻道、允許嵌入的影片，內容不能跟文章矛盾。
  - **開頭情境圖**：AI 生成（frontmatter `cover`＋`cover_alt`，檔案 `src/assets/covers/<slug>.webp`），只當情境、不示範步驟；不能有字、數字、logo、面板、整台家電；每張人工目檢。
  - 不用：說明書截圖、影片截圖（版權）、AI 畫步驟或零件。
