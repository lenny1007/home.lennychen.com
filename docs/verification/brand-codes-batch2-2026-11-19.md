## 方法
獨立 fresh-context agent 以推翻為目標：能用 WebFetch 重抓的（金鼎官網、LG 支援頁、奇美 P188 系列 PDF、夏普 PDF 文字層、LG 手冊 PDF）對原文；聲寶（擋程式）、奇美掃描檔、夏普代碼圖片只能對 TSV。修正後另派 fresh-context agent 複查。

| 文章 | 判定 | 修正 |
|---|---|---|
| jinting-aircon-error-codes | 76 列全數對得上；小修後通過 | 電話改「官網列的電話」；補線上報修頁來源；刪「側面貼紙」；補 XT 吊隱只列 HRV-23XT 的說明 |
| sampo-aircon-error-codes | 不通過→修正後通過 | 漏收代碼 7（室內室外通訊故障，該列同時標了吊隱系列被篩掉），PF／NF、SF 兩表都補上；SF 差異改為 1、17、19（20 只差官網重複字，caption 註明）；PC 系列註明有 8A；刪未出自來源的貼紙說法 |
| chimei-washer-error-codes | 對得上；小修後通過 | 刪 404 型號的舉例；U15 補 P20LVS「衣物太濕」 |

| lg-dehumidifier-display-codes | 小修後通過 | [O 改「設定或運行時顯示」；錯誤代碼句補「智慧診斷時」 |
