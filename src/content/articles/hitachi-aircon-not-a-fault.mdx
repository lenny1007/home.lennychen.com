## 先看看是不是這些正常現象

下面這些情形，日立說明書都明確寫了「不是故障」。

### 聲音

| 聽到的聲音 | 原因 |
| --- | --- |
| 像流水或沸騰的聲音 | 冷媒在管路裡流動，開機和停機時特別明顯 |
| 「噗咻」「咔噹」 | 閥門在切換 |
| 「咻、咻」「啪、啪」 | 機體因溫度變化熱脹冷縮，或運轉剛開始時室內機馬達轉速改變 |
| 室外機聲音忽大忽小 | 壓縮機在調整轉速 |

### 看到的、聞到的

| 現象 | 原因 |
| --- | --- |
| 冷氣或除濕時，出風口冒白霧 | 室內潮濕的空氣被冷風冷卻，凝結成霧；低溫多濕時比較容易看到 |
| 吹出來的風有味道 | 室內的氣味被機器吸附後又吹出來 |
| 暖氣時，室外機冒蒸氣 | 正在除霜 |
| 暖氣關掉後，室外機還在運轉 | 自動快速除霜 |
| 運轉指示燈從亮變閃再變亮（暖氣預熱中，或剛從冷氣切換成暖氣） | 保護回路和預熱感應器在動作，不是定時燈的故障閃爍 |

吹出來有味道，雖然不是故障，但機器內部髒了也會產生異味。這時可以參考[日立冷氣濾網怎麼洗](/articles/hitachi-aircon-filter-cleaning/)，內部則要請專業清潔。

## 什麼情況才該叫修

如果定時燈在閃、顯示器出現數字，那是機器在回報故障，處理方式見[日立冷氣定時燈閃爍怎麼辦](/articles/hitachi-aircon-timer-light-blinking/)。

另外，保險絲或斷路器一直跳、有水或異物跑進機器、電線破損或發熱，都要馬上關電源、聯絡經銷商。

## 適用機種

本文依據台灣日立 RAS-22YSK～71YSK 等機種的使用說明書整理。有凍結洗淨功能的機種，運轉時的特殊現象請看說明書的凍結洗淨章節。
