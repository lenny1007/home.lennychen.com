## 運轉燈在閃，不一定是壞了

國際牌說明書裡，代表故障的是**定時燈**持續閃爍（處理方式見[國際牌冷氣定時燈閃爍怎麼辦](/articles/panasonic-aircon-timer-light-blinking/)）。**運轉燈**閃爍則有下面幾種正常情況：

| 什麼時候 | 說明書的說法 |
| --- | --- |
| 暖氣剛開始運轉 | 為了防止吹出冷風，請稍候片刻 |
| 暖氣運轉中，風停了 | 室外溫度低或濕度高時，霜會聚集在室外機上，正在除霜；除霜時間最長 12 分鐘 |
| 預約開機前、在自動運轉行程中 | 為了開機時達到設定溫度，冷氣機會提前 0～50 分鐘運轉；若在自動運轉行程，運轉燈會持續閃爍 |
| 一對多機種，兩間以上同時開（QX、RX 系列） | 各室選了不同的運轉模式，可能無法正常運轉，運轉燈會閃到調回相同模式為止 |

## 風的狀況

| 現象 | 原因 | 適用 |
| --- | --- | --- |
| 開機後風沒有馬上吹出來 | 暖氣初運轉，為了防止吹冷風要稍等；或是在自體淨行程，為了不讓室內熱交換器產生的異味隨風吹出，冷氣機約 1 分鐘不吹風 | 三個系列 |
| 運轉中風停了 | 暖氣運轉時在除霜，除霜時間最長 12 分鐘 | 三個系列 |
| 暖氣時，室內風扇反覆停止又運轉 | 在檢查室內溫度 | J 系列 |
| 除濕（風量自動）時，室內機一直停停走走 | 這樣運轉是為了達到除濕的目的 | J 系列 |
| 暖氣關機後又自己動起來 | 為了避免顯示溫度和室內溫度差太多，會進行餘熱排除行程，這時風向導片重新打開、以微速送風，之後停止；溫度顯示「--」，約 60 分鐘後恢復正常顯示 | QX 系列 |

## 看到的、聽到的、聞到的

| 現象 | 原因 | 適用 |
| --- | --- | --- |
| 出風口冒出霧氣 | 屋內的空氣被冷氣機吹出的冷空氣影響，形成霧狀 | 三個系列 |
| 有時發出「ㄅㄨ ㄒㄩ」聲 | 除霜運轉或運轉停止時，冷氣機內部冷媒流動切換的聲音 | 三個系列 |
| 像水流的聲音 | 冷氣機內部冷媒流動的聲音 | 三個系列 |
| 發出「ㄆㄧ ㄒㄧ」聲 | 溫度變化時，冷氣機塑膠部分伸縮的聲音 | QX、RX 系列 |
| 從 nanoe 奈米水離子產生部發出「嘎」或「咻」聲 | 奈米水離子產生時的聲音，會隨房間濕度變大變小，不影響效果；在意的話可以用遙控器上的 nanoeX 按鈕關掉這個功能 | QX、RX 系列 |
| 沙沙聲 | nanoe 作用時的聲音；對聲音敏感的人，說明書建議就寢時把 nanoe 模式取消 | J 系列 |
| 出風口右側有特殊氣味 | nanoe G 產生的正常味道 | QX、RX 系列 |

## RX 系列：nanoeX 燈一直閃

RX 系列說明書寫到，冷氣運轉中 nanoeX 燈持續閃爍時，要先關機、切斷電源，再同時清洗濾網，並用乾的棉花棒清潔 nanoe-G 產生器（棉花棒不要沾酒精等液體）。清潔的位置和方式，請照說明書第 35 頁的圖示操作。濾網的清法見[冷氣濾網怎麼洗](/articles/aircon-filter-cleaning/)。

## 什麼情況才該叫修

定時燈持續閃爍，或是有燒焦味、漏水、斷路器常跳、電線發熱，就不是上面這些正常現象。請關閉無熔絲開關，聯絡經銷商或服務站，詳細見[國際牌冷氣定時燈閃爍怎麼辦](/articles/panasonic-aircon-timer-light-blinking/)。

## 適用機種

本文依據台灣國際牌三份說明書整理：分離式 CS-QX22FA2～CS-QX110FA2（QX 系列）、隱藏式 CS-J22BDA2～CS-J110BDA2（J 系列）、分離式 CS-RX22GA2～CS-RX125GA2（RX 系列）。表格「適用」欄寫的是哪幾份說明書有列這一項；其他系列請以你家冷氣的說明書為準。
