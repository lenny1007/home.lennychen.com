三菱電機（Mitsubishi Electric）和三菱重工是不同品牌，說明書和處理方式也不一樣。先看室內機或說明書上的標示，型號開頭是 MSZ-、MSY- 的才是本文說的三菱電機機種。

## 先分清楚：哪一種閃法

三菱電機 GT、GA 系列的室內機有兩顆「運轉指示燈」（依機型上下或左右排列）。說明書提到的閃燈有兩種，處理方式不同：

| 你看到的 | 說明書怎麼說 | 怎麼做 |
| --- | --- | --- |
| 左側／上方的運轉指示燈閃爍 | 列在「請停止使用空調機並聯絡經銷商」的情況 | 停止使用，聯絡經銷商 |
| 室內機上**所有的 LED 燈**都在閃 | 檢查水平葉片是否已正確安裝 | 檢查水平葉片，裝好後再開 |

### 左側／上方的運轉指示燈閃爍

說明書的「疑難排解」把這個情況列為要**停止使用、聯絡經銷商**的狀況。說明書另外註明一個例外：「機組處於待機狀態下多台機組的燈號閃爍時」。

台灣說明書**沒有列出閃燈代表哪一種故障**，也沒有教使用者讀代碼，所以不要自己猜原因。處理方式是：

1. 停止使用冷氣。
2. 聯絡三菱電機經銷商。說明書封底的台灣三菱電機服務專線是 0800-52-30-30。

### 所有 LED 燈一起閃

說明書在清潔出風口的步驟裡寫明：**沒有正確安裝水平葉片，電源開啟時所有的 LED 燈會閃爍**。如果你剛清潔過出風口、拆過葉片，先關電源，照說明書把水平葉片裝回去，再開機看看。

葉片的拆裝方式見[三菱電機冷氣濾網怎麼洗](/articles/mitsubishi-electric-aircon-filter-cleaning/)。

## 運轉指示燈平常的樣子

運轉指示燈本來就會隨著室溫改變亮法，這是正常的：

| 指示燈 | 意思 |
| --- | --- |
| 兩顆都亮 | 機器正在運轉，室溫距離設定溫度約 2°C 或以上 |
| 只亮一顆、另一顆不亮 | 室溫接近設定溫度（相差約 1 到 2°C） |

## 這些情況，請停止使用並聯絡經銷商

說明書列出的清單如下：

- 室內機漏水或滴水
- 左側／上方的運轉指示燈閃爍（多台機組在待機狀態下的燈號閃爍除外）
- 斷電器經常故障
- 室內有電子開關型日光燈（具電子式安定器的日光燈等），機器收不到遙控器訊號
- 冷氣運轉時干擾收音機或電視訊號（說明書寫受影響的設備需要加裝強波器）
- 聽到異常的聲音
- 發現冷媒洩漏

安全注意事項另外提醒：

- **有燒焦味等異常狀況**：立即停止運轉，拔下電源插頭或關閉斷電器，聯絡經銷商。異常時還繼續用，可能造成故障、火災或觸電。
- **懷疑冷媒洩漏**（冷氣、暖氣突然沒效果時可能是原因之一）：立即停止運轉，讓房間通風，再聯絡經銷商。

<SafetyNote>冷媒、電路和室內機內部的檢修需要專業知識，請交給三菱電機經銷商或合格技師，不要自己拆開機器。</SafetyNote>

## 叫修前，先自己檢查這些

說明書的疑難排解表寫明：檢查過這些項目後還是不能恢復運作，再停止使用並聯絡經銷商。

### 完全不能操作

- 斷電器有沒有打開
- 電源插頭有沒有插好
- 是不是設了定時開機

### 開機後要等一下才動

機組重新啟動後要等 3 分鐘才開始運作，是微處理器的保護機制，等一下就好。

### 冷氣不冷、暖氣不暖

- 設定溫度是否適當
- 風速是否太小（說明書建議改成高速或超高速）
- 濾網是否乾淨（清法見[三菱電機冷氣濾網怎麼洗](/articles/mitsubishi-electric-aircon-filter-cleaning/)）
- 室內機的風扇或熱交換器是否乾淨
- 室內機、室外機的進氣口或出風口有沒有被擋住
- 門窗有沒有開著
- 房間大小、環境溫度等條件，可能要一段時間才達到設定溫度，或無法達到
- 室內同時用通風扇或瓦斯爐，冷氣負擔增加，冷房效果會打折
- 室外溫度太高時冷房效果會變差；室外溫度太低時暖房效果會變差（暖房只限 MSZ 冷暖機種）

### 遙控器沒反應

- 遙控器電池是否沒電
- 電池正負極（+、-）有沒有裝對
- 是不是按到別的家電的遙控器

遙控器暫時不能用時，可以按室內機上的**緊急操作開關（E.O. SW）**。每按一次會依序切換緊急冷房 → 緊急暖房（只限 MSZ）→ 停止，設定是溫度 24°C、風速中等、上下風向自動。說明書註明開始運轉後的前 30 分鐘是試運轉，不會控制溫度，風速設為高。

### 自己開機、自己關機

- 有沒有設定進階定時
- 這兩個系列有**自動重新啟動功能**：停電或關掉主電源前沒有先用遙控器停機，電源恢復後機器會用原本的模式自己開始運轉。不想要這個功能，說明書寫要聯絡檢修人員改設定。

## 說明書對這些現象的解釋

### 室內機

| 現象 | 說明書的解釋 |
| --- | --- |
| 出風口冒霧氣 | 冷空氣迅速冷卻室內空氣中的水氣，變成霧氣 |
| 水平葉片停一陣子再重新擺動 | 為了讓葉片正常運作 |
| 冷氣或除濕朝下吹 0.5 到 1 小時後，風向自己變成水平，遙控器也調不了上下 | 避免水氣凝結滴落 |
| 暖氣時風向自己變成水平 | 出風溫度過低，或剛做完除霜 |
| 暖氣途中停止運轉約 10 分鐘 | 室外機在除霜；室外溫度過低或濕度過高時會結霜 |
| 暖氣剛開，風出得慢 | 機器正在準備送出暖氣，稍等即可 |
| 開主電源後沒按遙控器就開始運轉 | 自動重新啟動功能 |
| 塑膠外殼用久變黃 | 紫外線和溫度等因素造成，不影響功能 |
| 吹出的風有怪味 | 機器吸附了牆壁、地毯、傢俱、衣物的氣味再吹出來；也要檢查濾網、風扇和熱交換器是否乾淨 |

### 聲音

| 聽到的聲音 | 說明書的解釋 |
| --- | --- |
| 爆裂聲 | 前面板等零件因溫度變化熱脹冷縮 |
| 「冒泡」聲 | 排水軟管吸入外面的空氣；室外風大時也會 |
| 機械聲 | 風扇或壓縮機開關時的切換聲 |
| 水流聲 | 冷媒或凝結水在機器裡流動 |
| 嘶嘶聲 | 機器內冷媒流動切換 |

### 室外機

| 現象 | 說明書的解釋 |
| --- | --- |
| 壓縮機在運轉，室外機風扇卻沒轉，或轉一下就停 | 冷房時室外溫度變低，風扇會間歇運轉來維持冷房能力 |
| 室外機滴水 | 冷房、除濕時配管溫度降低而凝結水氣；暖房時熱交換器的凝結水，或除霜融化的水滴下來 |
| 室外機冒白色煙霧 | 暖房除霜產生的水蒸氣 |

## 適用機種

本文依據台灣三菱電機兩份室內機操作手冊整理：

- MSZ-GT／MSY-GT 22～90NJ（文件編號 JG79Y925H01）
- MSZ-GA／MSY-GA 22～100NJ（文件編號 VG79N495H01）

MSZ 是冷暖機種，MSY 是冷專機種。其他系列的顯示方式可能不同，請以你家冷氣的說明書為準。不同品牌的處理方式，可以對照[日立冷氣定時燈閃爍怎麼辦](/articles/hitachi-aircon-timer-light-blinking/)。
